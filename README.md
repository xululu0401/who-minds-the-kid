# 孩子放假谁来带

孩子放春假、秋假，爸妈照常上班：把爸妈、老人、托管班哪个半天有空、最多带几个半天、每半天花多少填进格子，算出最省的排法（现金 + 年假折价）、哪个半天谁都排不上、谁多帮一个半天能省多少、谁临时来不了要多花多少。

- 体验：https://xululu0401.github.io/who-minds-the-kid/
- 求解：最小费用最大流（先排上尽量多的半天，再让合计最少；并列时名单靠前优先），精确最优。
- 测试：`node --test tests/core.test.cjs`；独立参考 `python3 tests/ref.py`（itertools 全枚举 + Fraction，300 组）；注入 `node tests/inject.cjs`。
- 全部在浏览器里算，不联网。默认人物、时间与价格为虚构示例；年假折价由使用者自定。
